Análise de Preços Internacionais de Combustíveis (1990 - 2008) 
Este projeto realiza uma Análise Exploratória de Dados (EDA) sobre a evolução dos preços da gasolina em diversos países ao longo de quase duas décadas. O objetivo é utilizar ferramentas de Ciência de Dados para observar tendências de mercado, volatilidade e o impacto de políticas econômicas no preço final ao consumidor.

 Tecnologias e Ferramentas
O projeto foi desenvolvido utilizando o seguinte ecossistema:

°Linguagem: Python 3.13+

°Ambiente de Desenvolvimento: Anaconda

°IDE: JupyterLab

°Bibliotecas de Manipulação e Análise:

     °Pandas: Carregamento de arquivos CSV, filtragem de dados e manipulação de DataFrames.

    °Matplotlib: Geração de gráficos de linha e visualização de tendências.

 O que o projeto analisa?
A análise foca na comparação direta entre diferentes economias, como Alemanha, México e Coreia do Sul. Através do código, é possível identificar:

1.Top 3 países com gasolina mais cara em 2008: Identificados como Alemanha, Itália e França.

2.Top 3 países com gasolina mais barata em 2008: México, EUA e Canadá.

3.Comparativos de Volatilidade: Onde observamos que países desenvolvidos como a Alemanha possuem preços mais elevados e voláteis, enquanto o México apresenta uma linha de preços mais estável em certos períodos.

 Conclusão Econômica
Como estudante de Economia, este projeto permitiu visualizar como a dependência energética e a carga tributária diferem entre as nações. Enquanto países como a Coreia do Sul mostram sensibilidade a crises globais por serem dependentes de importação, o México demonstra o impacto de subsídios e maior controle estatal na estabilização dos preços.
